# 待老师确认的问题

以下问题不阻止使用演示规则开发，但在真实赛事启用前必须留下确认人、日期、依据文件和结论。未得到答复时不能自行补成“学校规则”。

| 编号 | 需要确认的问题 | 为什么影响实现 | 当前默认 |
|---|---|---|---|
| Q-001 | 本赛事采用哪一版规程、21 分还是 3×15？ | 决定局分、封顶、间歇、换边和测试 | 传统 21 分制演示规则，未核验 |
| Q-002 | 男单、女单、男双、女双、混双开设哪些组别？ | 决定报名和编排维度 | 均作为可配置项目，不默认全部开设 |
| Q-003 | 双打搭档、跨班/院和兼项有哪些限制？ | 决定报名校验和赛程冲突 | 只检查重复身份，细则待确认 |
| Q-004 | 种子如何产生，同班/同院是否回避？ | 决定抽签约束及人工调整说明 | 不自动推定 |
| Q-005 | 小组同分按什么完整顺序排名？ | 决定名次、晋级和解释页 | 不启用自动正式排名 |
| Q-006 | 弃权、退赛、取消资格和未完赛怎样计分？ | 影响积分、净胜分和后续签表 | 仅保留状态类型，不推导结果 |
| Q-007 | 规定间歇和两场之间最短休息时间是多少？ | 影响裁判提示和赛程冲突 | 规则参数留空待确认 |
| Q-008 | 现场抛硬币可否使用软件随机辅助？什么情况允许重抽？ | 决定记录字段和权限 | 允许记录两种来源，重抽需原因 |
| Q-009 | 主裁判、裁判长和管理员分别能做哪些更正？ | 决定服务端授权和审批流 | 普通裁判只撤销最近误录；复杂更正上交 |
| Q-010 | 比赛结果何时锁定，谁可以解锁？ | 决定状态机和审计 | 结果确认后普通裁判不可回写 |
| Q-011 | 更正影响已排或已开始后续比赛时如何处理？ | 决定是否自动重算或进入人工处置 | 后续已开始时阻止自动改写 |
| Q-012 | 公开查询允许展示哪些个人字段？ | 决定隐私投影和导出 | 仅姓名/单位/项目仍需确认 |
| Q-013 | 成绩册、秩序册和学校材料是否有固定模板？ | 决定报表布局和字段 | 不生成假模板 |

## 确认记录格式

每个问题确认后在本表追加：`确认结论`、`确认人`、`确认日期`、`依据文件/会议记录`，并同步更新[规则来源与版本](../03-竞赛规则/规则来源与版本.md)和[需求追踪矩阵](需求验收追踪矩阵.md)。口头意见不能写成官方规程；无法取得原始依据时标记“赛事组织者本地规则”。
