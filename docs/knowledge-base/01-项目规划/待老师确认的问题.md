# 待老师确认的问题

资料包 `badminton-rules-v1` 已把原来的多数占位项转为“用户已决定”或“项目默认”。项目默认仍须赛事组织者在发布前采纳、公示和冻结，不能写成老师或学校现行规程。

| 编号    | 原问题                      | 已落地决定                                      | 仍需赛事发布前确认          |
| ----- | ------------------------ | ------------------------------------------ | ------------------ |
| Q-001 | 正式规程、21 或 3×15           | 三个预设和自定义层次已确定；每场保存快照                       | 本赛事采用哪个 profile 及来源 |
| Q-002 | 开设哪些单项/组别                | 系统支持 MS/WS/MD/WD/XD 和自定义组别                  | 当届实际开设清单           |
| Q-003 | 双打、兼项和资格限制               | 资格/名额线下审核；双打发布后冻结；系统跨项目查冲突                | 线下资格与换人规程          |
| Q-004 | 种子和回避                    | 默认不自动设种子；有依据时手工指定；本院赛默认代表队软回避             | 是否采纳及具体代表队字段       |
| Q-005 | 小组同分排序                   | 胜场、直接胜负、全组净胜局、全组净胜分、抽签的规则链已确定             | 赛事组织者正式采纳          |
| Q-006 | WO/RET/DSQ/未完赛           | 分开记录、不补 21:0；未完成全部小组赛时排除全部相关统计但保留历史       | 纪律裁决和作用范围          |
| Q-007 | 间歇与场间休息                  | 预设间歇已定义；场间默认 60 分钟，裁判长可批 30—59，低于 30 拒绝     | 是否采纳默认休息政策         |
| Q-008 | 抛币和重做                    | 胜方可选先发、先接或场地；无效可重做，有效确认后禁止刷新重抽            | 现场无效判定细则           |
| Q-009 | 更正和接管权限                  | 主裁判记分/留痕纠错；裁判长裁决/接管/解锁；管理员不能直接改分           | 具体角色人员名单           |
| Q-010 | 结果何时锁定                   | 主裁判提交 → 裁判长复核锁定                              | 当届裁判长与退回流程         |
| Q-011 | 更正对后续比赛的影响               | 未开赛链先冻结再重排；已开赛/结束链禁止自动换人和抹历史                | 争议时具体裁决            |
| Q-012 | 公开字段                     | 服务端白名单已定义；联系方式、学号、医疗和内部记录默认不公开             | 是否公开姓名/代表队         |
| Q-013 | 成绩册模板                    | 已有明确标记模拟的 HTML/PDF 参考；不是校方正式模板                  | 是否提供学校正式版式/用章流程    |

## 确认记录格式

赛事采纳时记录：`确认结论`、`确认人`、`确认日期`、`依据文件/会议记录`，并同步更新[赛事执行规则 v1.0](../03-竞赛规则/赛事执行规则-v1.0.md)、[规则来源与版本](../03-竞赛规则/规则来源与版本.md)和[需求追踪矩阵](需求验收追踪矩阵.md)。无法取得外部正式依据时明确标记“赛事组织者本地规则”。
