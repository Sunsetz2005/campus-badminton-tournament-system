# 校园羽毛球赛事管理系统知识库

> [!warning] 权威源与当前状态
> 本目录在代码仓库中的版本是唯一权威源。Obsidian 中的同名目录是安全单向同步副本，不应直接编辑。当前只完成阶段 0，系统尚不能启动，业务功能均未实现。

## 项目目标

建设一套中文响应式网页应用，使电脑、平板和手机共享同一后端与权威数据，完成：赛事设置 → 报名审核 → 分组编排 → 赛程和裁判指派 → 临场执裁 → 成绩复核 → 名次/晋级 → 成绩册与公开查询。
