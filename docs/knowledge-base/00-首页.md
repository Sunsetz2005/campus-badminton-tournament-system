# 校园羽毛球赛事管理系统知识库

> [!warning] 权威源与当前状态
> 本目录在代码仓库中的版本是唯一权威源。Obsidian 中的同名目录是安全单向同步副本，不应直接编辑。2026-09-20 联合独立验收确认 S2-008、S2-009 通过，并对阶段 3 场地图工作台给出“有条件通过”；UI-01-B 与联合总判原为“不通过”，F-001—F-005 已由 Codex 本地修复、尚待独立复判。正式 BWF 规则采用、真机/真人裁判和生产部署仍为未测试/待核验，当前不进入阶段 4 或 UI-01-C。

## 项目目标

建设一套中文响应式网页应用，使电脑、平板和手机共享同一后端与权威数据，完成：赛事设置 → 报名审核 → 分组编排 → 赛程和裁判指派 → 临场执裁 → 成绩复核 → 名次/晋级 → 成绩册与公开查询。
