# 校园羽毛球赛事管理系统知识库

> [!warning] 权威源与当前状态
> 本目录在代码仓库中的版本是唯一权威源。Obsidian 中的同名目录是安全单向同步副本，不应直接编辑。阶段 1 已独立复验通过；阶段 2 的 S2-002、S2-003、S2-006 已独立复验通过，S2-001 部分通过后遗留的 S2-007 已修复待复验，阶段 3 未开始。

## 项目目标

建设一套中文响应式网页应用，使电脑、平板和手机共享同一后端与权威数据，完成：赛事设置 → 报名审核 → 分组编排 → 赛程和裁判指派 → 临场执裁 → 成绩复核 → 名次/晋级 → 成绩册与公开查询。
