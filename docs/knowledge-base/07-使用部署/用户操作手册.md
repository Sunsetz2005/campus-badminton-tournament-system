# 用户操作手册

当前软件尚未实现，本文件只说明未来手册结构和阶段 0 文档使用方法，不能作为产品操作证明。

## 当前可做：查看项目知识库

1. 从[知识库首页](../00-首页.md)查看项目范围和导航。
2. 从[需求追踪矩阵](../01-项目规划/需求验收追踪矩阵.md)确认某项功能是否实现、是否测试。
3. 从[待老师确认的问题](../01-项目规划/待老师确认的问题.md)记录赛事规则结论。
4. 从[测试记录](../05-测试验收/测试记录.md)查看实际命令和结果。

## 未来产品手册章节

- 管理员：创建赛事、配置项目和规则、账号与发布。
- 组织人员：报名审核、分组编排、赛程和裁判指派。
- 主裁判：接管比赛、抛硬币、开局、逐分、换边、撤销、更正和提交。
- 裁判长：复核、接管、批准更正和处理影响。
- 公众：只读查询赛程、成绩和名次。
- 报表：生成、下载、打印、隐私检查和失败恢复。

每一章只有在真实功能完成并经过浏览器操作后才能填写截图与步骤。模拟界面、设计图和自动化夹具不能标成用户实测。
