# 用户操作手册

阶段 1 可执行登录、查看本人授权范围和公开模拟赛事。报名、编排、逐分执裁、成绩和报表仍未实现；本文件不能作为完整产品手册。

## 当前可操作页面

- 首页：查看当前阶段和功能边界。
- 登录：使用本机种子创建的测试身份；不开放注册。
- 赛事管理：管理员查看本人赛事范围，只读。
- 我的执裁：临场裁判查看本人真实指派，只读；控制会话只通过测试 API 验证，尚无裁判 UI。
- 公开查询：读取服务端白名单模拟数据。
- 设置：查看当前账号状态和赛事角色。

## 当前可做：查看项目知识库

1. 从[知识库首页](../00-首页.md)查看项目范围和导航。
2. 从[需求追踪矩阵](../01-项目规划/需求验收追踪矩阵.md)确认某项功能是否实现、是否测试。
3. 从[赛事执行规则 v1.0](../03-竞赛规则/赛事执行规则-v1.0.md)查看已整理的赛事方案，再从[待老师确认的问题](../01-项目规划/待老师确认的问题.md)区分项目默认值与仍需赛事采纳的内容。
4. 从[成绩册与公开查询模板说明](../08-成果材料/成绩册与公开查询模板说明.md)确认模拟模板边界；这些模板不是可操作的软件页面。
5. 从[测试记录](../05-测试验收/测试记录.md)查看实际命令和结果。

## 未来产品手册章节

- 管理员：创建赛事、配置项目和规则、账号与发布。
- 组织人员：报名审核、分组编排、赛程和裁判指派。
- 主裁判：接管比赛、抛硬币、开局、逐分、换边、撤销、更正和提交。
- 裁判长：复核、接管、批准更正和处理影响。
- 公众：只读查询赛程、成绩和名次。
- 报表：生成、下载、打印、隐私检查和失败恢复。

每一章只有在真实功能完成并经过浏览器操作后才能填写截图与步骤。当前 5 条 Playwright 结果属于自动化 Chromium 验收，不等于真实手机、平板或老师人工验收。

## 学院团体赛：负责人报名与抽签（阶段 4-B）

**赛事管理员**

1. 新建赛事时在「比赛项目」里点「＋ 团体赛」，按规程调整小场顺序（默认男单、女单、男双、女双、混双）与名单人数；已有赛事可在「赛事概览 → 新增项目」添加团体赛（使用默认设置）。
2. 在「队伍与负责人」为每个学院新建队伍，并为负责人开通账号（填姓名和邮箱）。页面会显示一次**初始口令**，请当场交给负责人；刷新后无法再看到，丢失只能「重置口令」。
3. 把赛事阶段推进到「报名中」，通知各学院负责人提交名单。
4. 在「报名审核」逐份通过团体名单（与个人报名同一界面），通过后生成以学院命名的报名单位。
5. 报名结束后把阶段推进到「报名截止」，进入「抽签编排 → 团体赛」：确认建议赛制，需要时设置种子并写依据，点「生成抽签草稿」。可反复重抽或手动交换/移组（须写原因）。核对无误后勾选确认并「正式发布抽签」。
6. 发布后名单冻结。若发现漏报、错报，需由本赛事**裁判长**在任何比赛开始前撤销发布，再重新抽签。

**学院负责人**

1. 用管理员给的邮箱和初始口令登录，按提示先设置自己的新口令（至少 12 位）。
2. 打开「我的队伍」，逐行填写队员姓名、学号、性别（联系方式选填），点「提交名单」。页面会直接列出不符合要求的地方（人数、男女人数、学号重复等）。
3. 审核前可以修改或撤回名单；审核通过后如需调整请联系赛事管理员。

4-D 起名单中每名队员还要勾选**报项**（可参加男单/女单/男双/女双/混双中的哪几项，按性别只显示可报的项目）。每场对抗只能从报了该项的队员里派人上场。

## 学院团体赛：出场名单、对抗结果与名次（阶段 4-D）

**学院负责人**

1. 抽签发布后，「我的队伍」会列出本队的每一场对抗。点「排出场名单」，为五个小场逐一选人（只列报了该项的队员）。同一名队员可以上多个小场，页面会提示兼项次数。
2. 提交后，对方交齐前双方互相看不到名单，你仍可修改；两边都交齐后同时公开并**锁定**，之后如需换人（如伤病）只能找裁判长。
3. 比赛过程中可在同一页查看大比分与每个小场的结果（以裁判长复核锁定为准）。

**赛事管理员**

1. 「团体对抗」页查看每个项目的对抗进度。进入单场对抗可看到双方是否已提交（交齐前看不到内容）；负责人无法提交时可「代交」。
2. 小场结果经主裁判提交、裁判长复核锁定后自动计入对抗：小组/循环赛五个小场打满；淘汰赛一方先胜 3 场即结束，未开始的小场记为「未进行」，胜者自动进入下一轮。

**裁判长**

1. 名单公开后，可在单场对抗页为尚未开始的小场调整上场队员，必须写原因。
2. 小组对抗全部结束后，在积分榜下确认名次；成绩无法区分时须先现场抽签，再按结果调整这几队的先后并写明抽签情况。确认后出线学院自动填入淘汰签位。
3. 若重开某个小场的结果导致对抗胜负或小组名次变化，系统会自动撤回已回填的下一轮签位；下一轮已开赛时会拒绝重开。

排名依据（对抗胜场 → 相互胜负 → 小场差、局差、分差 → 抽签）是项目默认，正式比赛前请组织者按规程确认。

## 赛程与裁判排班（阶段 4-C）

**赛事管理员（赛事后台 →「赛程排班」）**

1. 「场地与时段」：按场馆实际数量追加场地（例如 8 块），填写比赛日与每天的开放时段，确认团体小场/个人项目的预计时长、换场时间、淘汰赛每场对抗用几块场地、出场名单提前多少分钟截止。预计时长只用于排程和推算延误，不是保证时长。
2. 「草稿编排」→「生成排程建议」：可以先只排小组赛、晋级确定后再排淘汰赛。小组赛一组一块场地，每场对抗的五个小场在同一块场地连打；淘汰赛一场对抗两块场地同时打。建议不保证最优，排不下的比赛会说明原因。
3. 逐场「调整」或「整场对抗重排」，每次保存都会立即检查。红色是**硬冲突**，必须改掉才能发布；黄色是**警告**（例如晋级者未定时的「暂定」、未指派裁判），发布前要勾选确认已逐项核对。
4. 「发布赛程」：裁判的「我的执裁」随即出现带时间和场地的比赛，已排定的比赛进入公开赛程。以后再改时同样先改草稿再发布，「发布记录」里能看到每一版改了什么。已经开始的比赛不会被移动。
5. 场地临时不能用：在「场地与时段」里关闭该场地，已排在上面的比赛会变成硬冲突，改到其他场地后重新发布。
6. 系统**不检查**运动员两场之间的休息时间，由现场裁判掌握。

**裁判长**

- 「我的执裁」→「现场看板」：按时间看每块场地的待开赛、进行中、已结束和延误（延误只是推算提示，是否顺延由你现场决定）。
- 某场需要临时换裁判：在该场「临时更换裁判」里选新裁判并写原因。原裁判的设备立即失去控制；新裁判进入工作台后接着记分。如果新裁判同一时间还有别的比赛，页面会提示，请到赛程草稿里改派后重新发布。

**学院负责人**

- 赛程发布后，「我的队伍」和单场对抗页会显示计划开始时间、场地和**出场名单截止时间**（默认开赛前 30 分钟）。截止后不能再提交或修改，请联系赛事管理员代交。
- 如果规程规定了兼项上限（例如男队员不得兼项、女队员最多 2 项），或者两个小场在赛程上同时进行，填写名单时页面会先提示，提交时服务器也会拒绝。


## 成绩、名次与晋级（阶段 6）

入口：后台赛事页的「成绩名次」（`/management/[slug]/results`）。赛事管理员、编排员与裁判长都能打开；只有裁判长角色的账号在后台只看得到这一页，需直接输入该地址进入。团体项目仍在「团体对抗」页确认积分榜。

**管理员/编排员：补录结果（仅结果记录）**

1. 在项目的「比赛结果」表里，对双方已确定、尚未开始的比赛点「补录结果」。
2. 选结局：正常完赛只填各局比分；弃权不填比分、选胜方；退赛/取消资格填已完成局与中断局的实际比分、选胜方；终止待裁决不选胜方。
3. 写明补录依据（例如纸质记分表编号），提交后是「待复核」。比分不合规则时会逐条说明原因。
4. 补录后的比赛不能再在裁判台逐分记分；需要改时请裁判长退回或重开。

**裁判长：复核、名次、更正**

1. 复核：对别人补录的结果填写复核意见后「复核锁定」或「退回」。自己补录的不能自己复核。裁判台记分的结果仍在裁判台复核锁定。
2. 名次：本组比赛全部锁定后出现确认面板。名次由成绩决定时直接确认；显示「并列待裁定」时先在现场抽签，按结果调整这几方的先后并写明抽签情况。确认后出线者自动进入淘汰签位。
3. 特殊结果：本组有弃权、退赛等结果时显示「有特殊结果待处理」。如决定排除不能完成比赛的一方，在排除面板选择并写明原因；确认名次前可以取消排除。
4. 更正：对已锁定的结果先点「更正前查看影响」。允许时，补录的结果可在这里写原因后重开；裁判台记分的结果到裁判台接管后「受控重开」，对话框同样先显示影响。后续比赛已经开始时不能自动更正，只能登记人工处置（维持原结果或线下裁决）。

**发布名次榜单**：赛事管理员或裁判长填写说明后「发布榜单新版本」。成绩被更正后页面显示「榜单需重新发布」，历史版本全部保留。当前名次规则是「校园演示排名方案」，正式使用前须组织者确认规程。已发布榜单暂未在公开页显示。

## 成绩册、导出与公开查询（阶段 7）

**后台：赛事后台 →「成绩册与导出」**（管理员、编排员、裁判长可进入）。

- **赛事数据表（Excel）**：「生成草稿」可带暂定比分，每页标「草稿」；「生成正式版」只有管理员与裁判长可用，只含经裁判长复核锁定的结果与已发布的名次榜单。名次在上次发布后有变化时会被拒绝，先到「成绩名次」重新发布榜单。数据没变时不会重复生成正式版。
- **成绩册（A4 打印网页与 PDF）**：「打开打印网页」按当前数据即时生成、不存档，用浏览器打印（⌘P / Ctrl+P，纸张 A4，勾选背景图形）；「生成 PDF」由服务器渲染同一模板并存档。
- **内部报名名单（Excel）**：含学号、性别、联系方式与审核记录，只有管理员与编排员能看到和下载，不得公开或外传。
- **已生成的文件**：每份文件都有版本、数据修订号、取数时间与 SHA-256；结果更正后再生成正式版，旧版标为「已被第 N 版替代」但仍可下载，内容不会被改写。页面会提示「数据已变化」。

**公开端：赛事页导航**

- **对阵与名次**：只列已确认的比分与胜方、裁判长确认的小组名次和已发布的最终名次；未确认的比赛只显示状态。榜单发布后又有更正、尚未重发时显示「名次更正处理中」。
- **成绩册**：下载组织者生成的当前正式版 PDF 与 Excel；没有正式版时明确说明。
- **比赛详情**：顶部标出「未开始 / 进行中 · 实时比分 / 暂定 · 待裁判长确认 / 已确认」，比赛确认前每 10 秒自动更新（页面在后台时暂停），「分享」里的链接是只读的，不含任何登录或记分凭据。
