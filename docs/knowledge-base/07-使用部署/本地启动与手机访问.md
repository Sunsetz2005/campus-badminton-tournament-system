## 阶段 1 计划验证

未来本地启动文档必须提供真实可执行命令，并记录：依赖安装、环境变量模板、数据库迁移、开发服务端口、健康检查、登录步骤和停止方式。手机访问还要核对监听地址、防火墙、同一局域网、HTTPS/安全上下文差异和不公开开发数据库。

`localhost` 成功不等于手机通过局域网 HTTP 可使用 Service Worker 或安全上下文能力。V1 的响应式网页和离线计分是不同能力；V1 明确不支持离线合并记分。
