# 本地启动与手机访问

> [!warning] 使用边界
> 当前是本机/局域网开发演示，不是可直接暴露公网的生产服务。
> 阶段 3 的场地图裁判工作台、服务端权威计分事务、控制会话租约与接管已经实现；
> 报名编排、分组排名、成绩册和真实公开赛程仍未实现。
> 没有做过真机手机/平板执裁，也没有配置 HTTPS。

## 当前 Mac 启动

仓库已通过 pnpm 项目 runtime 固定 Node 24.21.0，不需要修改系统 Node 26。

```bash
pnpm install --frozen-lockfile
pnpm exec node --version
pnpm run db:migrate
pnpm run db:seed
pnpm dev
```

预期 `pnpm exec node --version` 为 `v24.21.0`。浏览器访问 `http://127.0.0.1:3000`，健康检查为 `http://127.0.0.1:3000/api/health`。停止时在运行终端按 `Ctrl+C`。

首次检出需把 `.env.example` 复制为不提交的 `.env`，填写本机开发库和至少 32 字符的随机认证密钥。示例账号变量放在单独、被忽略的 `.env.seed`；知识库不保存密码。`pnpm run db:seed` 使用 Better Auth 提供的密码哈希创建本地身份，会拒绝未知数据库和生产环境；网页公众注册始终关闭。

## 浏览器验收路径

1. 打开首页，确认页面明确标注当前开发阶段，而不是完整系统。
2. 打开“公开查询”，刷新页面后模拟对阵仍存在；公开 API 不应出现邮箱、内部 ID、token 或审计字段。
3. 使用 `.env.seed` 中管理员身份登录，进入“赛事管理”可看到授权赛事；调用比赛控制接口应得到 403，管理员不能替代裁判。
4. 退出后使用临场裁判身份登录，“我的执裁”只显示已指派比赛；未指派的比赛不能取得控制权。
5. 进入已指派比赛的裁判工作台，取得本机控制权后可抛币、确认首发首接并加分；所有操作都要等服务器确认后才更新界面。
6. 打开“设置”核对当前账号和赛事角色；关闭服务再启动，公开数据和指派仍应存在。

## 测试与数据库隔离

首次运行前复制 `.env.test.example` 为 `.env.test`，填写独立的 `_test` 数据库连接、测试密钥和两个模拟身份。模板中 `BETTER_AUTH_URL` 固定为 Playwright 使用的 `http://127.0.0.1:3100`。

```bash
pnpm run lint
pnpm run typecheck
pnpm test
pnpm run test:e2e
pnpm run build
```

`pnpm test` 和 `test:e2e` 只接受数据库名以 `_test` 结尾。当前本机开发库为 `badminton_tournament_dev`，测试库为 `badminton_tournament_test`。自动化脚本不会重置或删除其他数据库；缺少 `.env.test` 时会明确提示先按模板创建。

## 局域网访问边界

开发服务监听 `0.0.0.0`，同一局域网设备理论上可通过 `http://Mac局域网IP:3000` 访问，但至今没有使用真实手机/平板或检查防火墙，因此局域网实机状态仍是“未运行”。不得把 localhost 或 Playwright Chromium 结果写成手机验收通过。

局域网 HTTP 也不等于安全生产部署；HTTPS、反向代理、备份恢复和生产密钥轮换均未执行。

### 安全上下文与命令 ID（R3-005）

电脑上的 `http://localhost` 是浏览器认可的**安全上下文**，手机通过 `http://Mac局域网IP:3000` 访问的明文 HTTP **不是**。
`crypto.randomUUID()` 只在安全上下文可用，因此两者的浏览器能力并不相同。

裁判工作台在进入可写界面**之前**检测所需能力，不会等到按加分时才抛原始异常：

| 访问方式 | 命令 ID 来源 | 界面行为 |
|---|---|---|
| HTTPS 或 `localhost` | `crypto.randomUUID()` | 正常可写 |
| 局域网明文 HTTP，浏览器提供 `crypto.getRandomValues` | 按 RFC 4122 第 4 版从密码学安全随机字节构造 UUID | 可写，但页面常驻提示「正式执裁请改用可信 HTTPS」 |
| 两种安全随机源都没有 | 无 | 保持只读，并显示可理解的原因 |

兼容路径**没有**使用 `Math.random`，也**没有**关闭浏览器安全策略、认证或 CSRF。
但只解决命令 ID **不等于** 手机执裁已经可用：正式执裁仍需可信 HTTPS、与之匹配的 `BETTER_AUTH_URL` 认证来源、跨设备登录验证和真机试用，这些**都还没有做**。
