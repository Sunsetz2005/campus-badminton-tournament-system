### 2.3 一处「看似缺陷、实为取证假象」

改造后 fullPage 截图中出现「跳到主要内容」跳转链接压住场地。
实测该元素 `position: fixed`、`transform: matrix(1,0,0,1,0,-63)`、`getBoundingClientRect().y = -55`、`matches(":focus") = false`，
即**页面上本就不可见**，是 Playwright `fullPage` 捕获把 `position: fixed` 元素按整页高度重排造成的假象。
因此**未改动产品样式**，只在截图脚本内用 `addStyleTag` 临时隐藏，并在脚本注释中写明原因。

## 5. 手工验收步骤

1. `pnpm run db:seed` 后 `pnpm dev`，用 `.env.seed` 中的「本地临场裁判」身份登录。
2. 打开 `/officiating/MD-DEMO-002`（双打）或 `/officiating/MS-DEMO-001`（单打）。
   `MD-DEMO-001` **故意未指派**，访问应得 403 `not_assigned`，可用来验证权限未被改坏。
3. 取得本机控制权 → 确认首发与首接 → 连点「右方+1」，观察羽毛球图标与姓名按规则同步换位。
4. 点「左侧换位」查看预览并确认，检查接发球员随之改变、比分不变。
5. 点「更正−1」走更正面板，确认历史保留且版本递增；断网后应显示最后确认状态而非假成功。
