## 证据要求

- 规则用例保存输入规则快照、逐命令序列和每步权威状态。
- 排名用例保存有效比赛集合、每次分层和最终解释。
- 并发用例保存两个设备会话、命令 ID、版本、租约代次和服务端响应。
- 导出/响应式用例区分资料包静态模板检查、项目自动化测试和真实设备人工验收。
