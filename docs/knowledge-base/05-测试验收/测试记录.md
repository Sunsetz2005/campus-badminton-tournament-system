### 失败用例的基线对照

`R3-003：服务器已落库但网关返回 502 时保留原 commandId` 单独运行 4/4 通过；只有与同文件前一条 R3-002 顺序执行时失败（整份文件 3 次均复现）。
失败时 trace 显示对 `commands/<id>` 的查询未被测试拦截、真实返回 200，客户端随即对账成功、恢复面板提前消失，测试随后等不到「查询原命令结果」按钮而超时。

为判断是否由本轮引入：在独立 git worktree 中检出 HEAD `0b3bc6d`（不含 4-0 与 4-A 任何改动），用新建的隔离库 `badminton_tournament_baseline_test` 运行同一文件，**以完全相同的方式失败**。
结论：这是既有的测试顺序依赖问题，不是 4-A 回归；本轮未修改该测试或计分界面代码，也未修复它。基线库保留未删除。

### 实现中发现并修复的缺陷

- 向导把未填写的报名时间以空字符串提交，服务端时间格式校验在转换前拒绝，导致「不设报名窗口」无法建赛。已改为空字符串等同于不设置，并补集成用例。
- 表单网格中「姓名」输入框因相邻字段有提示文字被拉伸错位；向导单项下拉框过窄截断文字。均为样式修正。
