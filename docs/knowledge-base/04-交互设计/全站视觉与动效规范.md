# 全站视觉与动效规范

2026-09-27 用户要求在部署前做一次全平台前端布局与组件优化：整体交互接近桌面系统的顺滑感，观赛台（现场看板）采用大型综合运动会官网式风格，裁判、领队、报名与后台各操作页面好用、符合操作逻辑、无障碍且美观。本文记录这次统一后的约定。

## 两套视觉语气

| 区域 | 语气 | 说明 |
|---|---|---|
| 后台、裁判、领队、登录、设置 | 桌面系统式 | 浅灰底、白色卡面、细线分隔、柔和阴影、半透明毛玻璃顶栏与分段控件 |
| 首页、赛事公开导航、现场看板、公开赛程与比赛详情 | 运动会官网式 | 深紫—蓝—湖绿渐变主视觉、底部多色飘带、斜体粗数字、深色实时比分卡 |

运动会风格只借鉴配色与版式气质，**不使用任何赛会标志、吉祥物或专有图形**。

## 样式分层

全局样式入口 `src/app/globals.css` 只做 `@import`，按层拆分到 `src/app/styles/`：

- `tokens.css`：设计令牌（颜色、圆角、阴影、缓动、时长、字体）与基础元素、键盘焦点、减少动态/高对比/减少透明偏好。
- `chrome.css`：吸顶毛玻璃顶栏、页面容器、页脚、页面切换与区块浮现动效。
- `components.css`：按钮、表单控件基线、状态徽章、卡片、提示与空状态、折叠区、资源状态、登录页、执裁指派卡。
- `portal.css`：首页主视觉、赛事卡片、赛事公开导航。
- `board.css`：现场看板。
- `workbench.css`：裁判工作台（自原 `globals.css` 原样迁出）。

旧变量名（`--ink`、`--muted`、`--paper`、`--surface`、`--line`、`--green`、`--blue`、`--gold`、`--danger`、`--focus`）保留，只调整取值，所以各功能 `*.module.css` 自动跟随。新增变量以 `--accent`、`--surface-2/3`、`--line-strong`、`--r-*`、`--shadow-*`、`--ease-*`、`--dur-*` 为主。

## 动效

- **页面切换**：`src/components/route-transition.tsx` 用 React `<ViewTransition>`，以路径为 key；旧页 140ms 淡出、新页 300ms 上浮淡入，顶栏固定不参与。同一路径下的 `router.refresh()`（看板每 15 秒刷新）和查询参数变化**不触发**动画。`::view-transition { pointer-events: none }` 保证过渡期间点击不丢失。
- **区块浮现**：主内容直接子区块依次浮现，最多错开 200ms。浮现使用独立的 `translate` 属性，不覆盖元素自身的 `transform`（例如居中外框的 `translateX(-50%)`）。裁判工作台内部不叠加浮现。
- **按压与悬停**：按钮按下缩放到 0.965 并以弹性曲线回弹；卡片悬停轻微上浮并加深阴影。
- **折叠区**：浏览器支持 `::details-content` 与 `interpolate-size` 时展开/收起带高度动画，不支持时直接切换。
- **实时状态**：「进行中」徽章与看板 LIVE 标记带脉动；看板主视觉底纹缓慢平移。
- **减少动态**：`prefers-reduced-motion: reduce` 下全部动画与过渡时长归零，页面切换直接替换，悬停不位移。

## 无障碍约定

- 所有交互元素保留键盘可见焦点（实线轮廓 + 柔光环），高对比模式下轮廓仍可见。
- 文字颜色在白底上不低于 4.5:1；`prefers-contrast: more` 下加深次要文字与分隔线、加粗边框，渐变主视觉改为纯色。
- `prefers-reduced-transparency: reduce` 下毛玻璃改为不透明白底。
- 主要触控目标不小于 44px（顶栏导航 36—40px 的胶囊在手机上为 40px，公开预览导航保持 48px）。
- 看板自动刷新**不再把快照时间放进实时播报区**，避免读屏每 15 秒被打断；只在手动刷新完成时播报一次；页面在后台标签页时暂停刷新，回到前台立即补一次。
- 登录表单：错误信息 `role="alert"` 并通过 `aria-describedby` 关联到输入框、输入框标 `aria-invalid`；提供「显示密码/隐藏密码」切换；429 限流给出单独提示。
- 看板分区用 `aria-labelledby` 关联标题；实时比分卡的已胜局数与当前局分数有中文 `aria-label`；VS 分隔对读屏读作「对」。
- 赛事公开导航与后台导航用 `aria-current="page"` 标出当前页，办赛流程用 `aria-current="step"` 标出当前阶段。

## 操作逻辑调整

- **后台**：赛事概览顶部新增「办赛流程」步骤条（赛事设置 → 报名审核 → 抽签编排 → 赛程排班 → 成绩名次），只按管理员推进的赛事阶段标出「当前阶段」与「已过阶段」，不猜测某一步是否「已完成」。后台二级导航改为吸顶分段控件，窄屏横向滚动。
- **裁判**：「我的执裁」卡片突出对阵双方，时间与场地单独一行，「进入执裁」为整宽主按钮；裁判长待复核卡片显示中文状态而不是枚举值。工作台页的顶栏不吸顶，把纵向空间留给场地。
- **手机顶栏**：≤800px 时顶栏换成两行，不再吸顶，随页面滚走；所有吸顶元素以 `--sticky-top` 为起点（桌面端等于顶栏高度，手机端为 0），不要再直接用 `--topbar-h` 算吸顶位置（2026-09-28 修复看板跳转条被顶栏遮挡）。
- **现场看板**：顶部分区跳转条（进行中/待处理/待开赛/已完成，带数量）吸顶；待开赛以时间轴行展示；只有结果锁定后才标出胜方，待复核比赛不提前宣布胜负；每张卡片都有「详情」入口。
- **首页**：主视觉显示公开赛事数、已公开赛程数与正在进行场次；赛事改为海报在上的卡片网格。
- **登录**：文案改为面向真实工作人员；登录后跳转只接受站内相对路径（修复 `//外站` 形式的开放重定向）。
