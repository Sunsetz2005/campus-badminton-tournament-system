# 页面与流程

阶段 1 建立了首页、登录、赛事管理、我的执裁、公开查询和设置的中文响应式骨架。阶段 3 已实现受保护的权威裁判工作台；报名、编排、排名、成绩册以及完整公开赛程/成绩仍未实现。每个写操作仍必须对应服务端权限和明确反馈。

当前 `/public` 固定读取 `phase-1-demo`，只证明服务端白名单骨架，不是完整公开查询。UI-01-A 已完成参考核验和设计规范；UI-01-B 已实现非生产显式开关控制的每日赛程/比赛详情隔离模拟预览，其中每日赛程的本轮视觉修正待用户确认。UI-01-C 真实公开接口尚未实现。

## 页面结构

| 区域 | 页面/能力 | 主要角色 | 关键状态 |
|---|---|---|---|
| 登录与工作台 | 登录、本人任务、赛事切换 | 内部角色 | 未登录、无权限、待处理 |
| 赛事设置 | 基本信息、项目、规则、场地、账号 | 管理员 | 草稿、开放报名、编排中、进行中、已归档 |
| 名册录入 | 手工录入、Excel/CSV 导入预览、双打成员、重复/错误处理 | 组织人员 | 草稿、预览、已导入、部分失败 |
| 分组编排 | 名单、种子、回避、循环/淘汰签表 | 组织人员 | 草稿、已发布、存在冲突 |
| 赛程调度 | 时间、场地、裁判、冲突检查 | 组织人员 | 未排、已排、冲突、变更待通知 |
| 主裁判工作台 | 接管、抛硬币、开局、记分、更正、提交 | 主裁判/裁判长 | 见[裁判端交互规范](裁判端交互规范.md) |
| 成绩复核 | 结果确认、更正申请、影响预览 | 裁判长/管理员 | 待复核、已锁定、更正中 |
| 名次晋级 | 小组排名解释、晋级、后续签位 | 组织人员 | 待结果、可计算、受更正影响 |
| 报表中心 | 基于锁定快照生成版本化成绩册、打印和替代记录 | 管理员/组织人员 | 草稿、已复核、已发布、已被替代 |
| 公开查询 | 服务端白名单返回赛程、成绩、名次和版本 | 公众 | 只读、脱敏、临时、正式、争议 |

## 三端界面边界

| 界面 | 目标 | 数据/权限边界 |
|---|---|---|
| 公开端 | 快速查询何时、何地、谁对谁、比分与正式结果 | 完全只读，只接公开发布与隐私投影；不得复用裁判状态接口 |
| 管理端 | 录入、编排、冲突处理、复核与发布 | 保留后台效率，所有写权限由服务端执行 |
| 裁判端 | 稳定 A/B、发接发/位置、比分、撤销、换边与控制权 | 继续使用权威事务、租约和命令接口，不套用公众列表布局 |

公开端详细规范见[亚运会网站参考与本项目界面规范](亚运会网站参考与本项目界面规范.md)和[公开赛程与成绩中心：页面与状态清单](公开赛程与成绩中心-页面与状态清单.md)。

## 主业务流程

| 步骤 | 输入 | 成功输出 | 阻断条件 |
|---|---|---|---|
| 创建赛事 | 名称、时间、项目和规则 | 赛事草稿 | 缺少必要规则确认 |
| 导入名册 | 线下审核结果、手工输入或表格 | 新增/重复/错误预览 | 字段缺失、重名未区分、双打成员错误 |
| 确认名册 | 导入预览、幂等键 | 参赛名单版本 | 重复批次、同项目重复、资格待复核 |
| 分组编排 | 已通过名单、种子、约束 | 可追踪签表 | 约束无解或人工调整未说明 |
| 安排赛程 | 签表、场地、时间和裁判 | 已排比赛 | 场地/人员/休息冲突 |
| 临场执裁 | 指派、租约、抛硬币和开局状态 | 权威逐分历史和结果 | 无权限、无租约、断网、版本冲突 |
| 复核排名 | 已确认结果、排名规则 | 可解释名次和晋级 | 结果未锁定、规则未确认 |
| 发布报表 | 已复核数据、公开范围 | 下载文件和查询页 | 隐私字段未确认、生成失败 |

## 公开端补充流程

1. UI-01-B 只在非生产显式开关下提供每日赛程和比赛详情的隔离预览，始终标注“模拟数据／界面预览”。
2. UI-01-C 只有在逐场发布快照、隐私投影、赛事时区日期、可信时间和公开投影版本契约具备后才接真实服务。
3. 对阵、排名、最终名次和成绩册继续等待权威业务服务；UI 不自行计算或伪造正式结果。

## 通用反馈要求

- 保存中、服务器已确认、待确认、冲突、只读和离线必须有不同视觉/文案，不能用同一个绿色提示代替。
- 破坏性或高影响操作显示对象、前后差异和原因输入。
- 移动端核心操作不依赖悬停；得分按钮足够大且双方不易误触。
- 页面刷新后从服务器恢复权威状态及待确认命令，不从旧 localStorage 猜测成功。
- 空状态、加载失败、无权限和数据冲突都提供下一步，而不是空白页。

## 模板边界

资料包的 `public-results-demo.html`、`results-booklet.html/pdf` 和 `demo-data.json` 只作为版式与字段参考。当前项目不复制其模拟成绩为真实数据，不把本地筛选当成公开查询功能，也不把固定 7 页排版当成动态报表已完成。集成要求见[成绩册与公开查询模板说明](../08-成果材料/成绩册与公开查询模板说明.md)。
