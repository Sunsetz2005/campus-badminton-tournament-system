# 截图与材料准备清单

`badminton-rules-v1` 资料包自带的 HTML/PDF 截图和模拟视口检查只证明静态模板在其生成环境中的表现，不是本项目截图、真实手机/平板验收或后台功能证据。

## 取证要求

每张截图记录日期、提交 SHA、运行环境、访问路径、角色和场景。画面中的学号、电话、邮箱、token 和真实密码必须脱敏。截图应来自同一次可复现运行，并与[测试记录](../05-测试验收/测试记录.md)对应。
