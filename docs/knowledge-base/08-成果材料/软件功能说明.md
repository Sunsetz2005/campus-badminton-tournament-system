# 软件功能说明

## 当前成果

阶段 0—2 的文档、安全同步、应用基础和纯规则引擎之上，阶段 3 已新增权威计分事务、事件/快照重建、写入租约、心跳/接管、响应对账和裁判工作台。报名、编排、排名与报表等完整赛事业务仍未完成。

## V1 计划功能

| 模块 | 计划能力 | 当前状态 |
|---|---|---|
| 工程与权限基础 | 应用启动、数据库会话、赛事角色和比赛指派校验 | 阶段 1 已实现并测试 |
| 赛事与权限 | 完整赛事设置、账号管理和授权 UI | 未实现 |
| 名册录入 | 五单项后台手工录入、Excel/CSV 导入、双打成员和重复校验 | 未实现 |
| 分组编排 | 种子/回避、循环赛、淘汰赛、人工调整 | 未实现 |
| 赛程裁判 | 时间场地、冲突检查、裁判指派 | 未实现 |
| 主裁判端 | 抛硬币、逐分、发接发、换边、撤销、更正、确认 | 阶段 3 已实现并通过本地自动化；真机/人工未测试 |
| 成绩名次 | 复核、排名解释、晋级和影响控制 | 提交、退回/锁定基础已实现；排名、晋级和影响控制未实现 |
| 成绩册 | 表格/PDF/打印、隐私和公式注入防护 | 未实现 |
| 公开查询 | 服务端白名单模拟赛事投影 | 阶段 1 基础已实现；完整赛程/成绩/名次未实现 |
| 可靠性 | 权威快照、幂等、版本冲突、租约、接管、响应丢失和断网安全 | 阶段 3 已实现并通过本地自动化；真机网络未测试 |

资料包现有 `public-results-demo.html`、`results-booklet.html/pdf` 和 `demo-data.json` 是模拟参考资产，不属于上表任何“已实现”功能。其哈希、版式和验证边界见[成绩册与公开查询模板说明](成绩册与公开查询模板说明.md)。

最终功能说明必须由需求追踪矩阵、真实代码、测试记录和界面截图共同支撑。规划文案不能单独作为软件功能完成证据。
