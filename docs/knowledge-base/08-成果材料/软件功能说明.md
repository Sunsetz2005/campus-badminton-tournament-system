# 软件功能说明

## 当前成果

阶段 0 的实际成果是需求和架构规划、26 份项目知识库文档，以及带路径、冲突、哈希和备份保护的单向同步工具。当前没有可运行的软件界面，不能把下列规划功能写成已实现。

## V1 计划功能

| 模块 | 计划能力 | 当前状态 |
|---|---|---|
| 赛事与权限 | 赛事设置、五类角色、服务端授权 | 未实现 |
| 报名审核 | 单打、双打、搭档、资格和审核 | 未实现 |
| 分组编排 | 种子/回避、循环赛、淘汰赛、人工调整 | 未实现 |
| 赛程裁判 | 时间场地、冲突检查、裁判指派 | 未实现 |
| 主裁判端 | 抛硬币、逐分、发接发、换边、撤销、更正、确认 | 未实现 |
| 成绩名次 | 复核、排名解释、晋级和影响控制 | 未实现 |
| 成绩册 | 表格/PDF/打印、隐私和公式注入防护 | 未实现 |
