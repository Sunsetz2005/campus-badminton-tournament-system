# 2026-09-28 开发日志

## 用户要求

演示管理员升为平台管理员；重跑演示种子；服务器上管理员、裁判员、领队改为简单用户名登录并统一演示口令。

## 做了什么

- 启用 Better Auth `username` 插件（服务端 `src/server/auth/auth.ts`、客户端 `src/lib/auth-client.ts`），迁移 `20260928120000_username_login` 给 `users` 加可空唯一 `username` 与 `displayUsername`。
- 登录页「账号」框：含 `@` 按邮箱登录，否则按用户名登录；失败提示改为「请检查账号、密码或账号状态」。
- 种子新增可选用户名变量与可选模拟领队（绑定团体赛演示赛事 T01），模拟身份不强制首次改口令。
- 部署到演示站并重跑种子，详见 [备份恢复与部署](../07-使用部署/备份恢复与部署.md)。

## 注意

- 用户名、口令只在服务器 root-only 配置，不入库。
- 演示口令短于 12 位，是用户对演示站的明确要求；改口令流程仍要求至少 12 位。
- 这次不属于 prompt-kit 任何阶段。

## 两处前端问题修复（用户在演示站反馈）

- **「我的执裁」按钮文字看不见**：`.card > a` 给卡片内链接统一上蓝色，优先级高于 `.button`，把「进入执裁」等按钮的白字也染成了蓝色，与蓝色按钮底色重合。改为 `.card > a:not(.button)`（`src/app/styles/components.css`）。
- **手机端观赛台顶部遮挡**：窄屏顶栏换成两行（实测约 115px），但吸顶元素按 `--topbar-h: 56px` 计算起点，现场看板的分区跳转条滚动后钻到顶栏下面，点不到。新增 `--sticky-top` 作为吸顶起点（桌面端等于 `--topbar-h`，≤800px 为 0），手机上顶栏改为随页面滚走；看板跳转条、分区锚点偏移、后台二级导航与后台赛程日期标题统一改用 `--sticky-top`。
- 验证：Chromium 375×812 下滚动后跳转条贴屏幕顶端且可点击；桌面端顶栏仍吸顶；lint 通过；Playwright 93/93。未在真机上验证。
