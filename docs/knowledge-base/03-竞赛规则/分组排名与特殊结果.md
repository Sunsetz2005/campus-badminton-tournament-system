# 分组排名与特殊结果

## 分组与编排原则

- 分组、种子、同单位回避和晋级数量必须来自赛事规程或组织者确认。
- 自动生成后允许人工调整，但保存调整前后签位、操作者和原因。
- 晋级签位引用上游比赛或小组名次来源，不复制成失去来源关系的姓名文本。
- 编排算法必须可重现：保存随机种子、输入名单版本和约束结果。

## 排名配置

系统需要可配置、可解释的排名规则链，例如比赛积分、相互战绩、净胜局、净胜分等；但本项目目前没有获得正式赛事规程，因此不固定具体先后顺序。

每次排名计算应保存：

- 采用的规则 profile 和版本；
- 输入比赛结果及其版本；
- 每一步比较指标；
- 并列是否解除、使用了哪一条规则；
- 最终名次和晋级来源。

界面应允许查看“为什么排在这个位置”，不能只输出一个不透明序号。

## 特殊结果类型

| 类型 | 必须记录 | 待确认影响 |
|---|---|---|
| 暂停/恢复 | 原因、时间、操作者 | 最大暂停时长和恢复权限 |
| 重发球 LET | 发起时点和说明 | 是否影响当前发接发状态 |
| 弃权 Walkover | 弃权方、赛前/赛中、原因 | 比分表示、积分和净胜分 |
| 退赛 Retirement | 发生局/比分、退赛方、原因 | 已得分是否计入排名 |
| 取消资格 Disqualification | 决定人、依据、时间 | 已赛结果是否保留 |
| 取消/延期 | 原因、新安排 | 签表和裁判指派处理 |

特殊结果不是随意录入一组比分。每种类型都要有独立命令、授权、合法状态和可解释的排名投影。

## 更正与晋级

排名和晋级是比赛结果的派生数据，不是不可追踪的手填终值。上游结果更正时先计算影响；后续比赛未开始且规则允许时事务重算，后续比赛已开始时进入人工处置。详细控制见[换边撤销与更正](换边撤销与更正.md)。

## 当前禁止的假设

- 不假设所有校园赛事都使用同一同分规则。
- 不假设弃权一律记为固定比分。
- 不假设退赛与取消资格对排名等价。
- 不在缺少规程时用常识补齐种子、回避或最短休息时间。
