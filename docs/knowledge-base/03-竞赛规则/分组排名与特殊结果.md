# 分组排名与特殊结果

## 分组与编排默认

- 2—5 人/对默认单循环；6 人/对及以上默认小组循环＋淘汰，每组目标 4、允许 3—5，前 2 出线。
- 默认不自动设种子；有上届同项目成绩或组委会依据时手工指定并保存依据。小组阶段最多每组一个种子。
- 本院赛事默认按代表队 ID 做软回避；先保证不漏不重、人数均衡和种子位置，无法全部回避时列出冲突。
- 第一版不启用最好第三名。两组用 A1—B2、B1—A2；四组映射见[赛事执行规则 v1.0](赛事执行规则-v1.0.md)。
- 默认三四名赛；没有 5—8 名排位赛就不跨组强排 5—8。
- 发布保存名单快照、设置、算法版本、随机结果、操作者和版本；刷新不能重抽。人工调整保存前后签位和原因。

## 排名配置

采用以下可解释规则链作为项目默认，赛事发布前须组织者采纳：

1. 先按全部有效小组比赛胜场。
2. 恰好两人/对并列时看直接胜负。
3. 三人/对及以上并列时比较整个小组有效比赛净胜局。
4. 分层后只剩两人/对时回到直接胜负；仍有三人/对及以上再比整个小组有效比赛净胜分。
5. 净胜分后两人并列仍看直接胜负；三人/对及以上完全相同则保存裁判长组织的抽签结果。

不使用并列者“小循环”、得失分比例、报名时间、数据库 ID、拼音或种子顺位决胜。

每次排名计算应保存：

- 采用的规则 profile 和版本；
- 输入比赛结果及其版本；
- 每一步比较指标；
- 并列是否解除、使用了哪一条规则；
- 最终名次和晋级来源。

界面应允许查看“为什么排在这个位置”，不能只输出一个不透明序号。

### 已实现的演示方案（阶段 6，2026-09-27）

个人项目小组名次已按上面的规则链实现为明确命名的「校园演示排名方案 v1」（`src/domain/results/ranking.ts` 的 `CAMPUS_DEMO_RANKING`）。它是可运行的工程示例，**不是学校或 BWF 的正式规程**，页面也这样标注；组织者确认正式规则后应另建版本与黄金测试，旧方案保留以便复现历史结果。

- 只统计经裁判长复核锁定、且正常完赛（`NORMAL`）的组内比赛；待复核、进行中的比赛不计入，此时只显示「暂定」。
- 同胜场两方看直接对赛；缺少有效直接对赛时标为待处理，不自动定。
- 三方及以上依次比较整个小组的净胜局、净胜分，各层剩两方回到直接对赛；**不在缩小的子集上重算**。
- 仍完全相同时「并列待裁定」，由裁判长按抽签/裁定顺序确认并写明依据（时间、方式、见证人），只能调整并列的几方。
- 组内出现未处理的特殊结果（WO、RET、DSQ、终止）时不产生正式名次。裁判长可以决定排除不能完成本组比赛的单位：其全部对阵贡献不计，其他人对它的胜负同步不计，原比赛、比分和审计保留。排除是逐组人工决定，不自动触发。
- 每个名次都保存比较步骤，页面「为什么排在这里」逐步列出；确认时保存方案键与版本、名次顺序、并列组、裁定依据、排除决定与计入的比赛。

最终名次只输出赛制真正决出的名次：决赛定第 1、2 名；有三四名赛定第 3、4 名，没有时两名半决赛负者并列第 3；更早轮次负者记「并列第 5（八强）」等；小组未出线者不跨组排名；单循环取确认的名次。

待组织者确认：采用哪一条规则链；是否设三四名赛；特殊结果的正式处理办法（本方案只提供「排除该单位」一种）。

## 特殊结果类型

| 类型 | 必须记录 | 待确认影响 |
|---|---|---|
| 暂停 `SUSPENDED` | 原因、时间、操作者、完整现场状态 | 无正式胜者；恢复后接续 |
| 重发球 LET | 发起时点和说明 | 不产生得分，发接发按规则保持 |
| 弃权 `WO` | 赛前/未到、确认人、原因 | 未打局留空，不补 21:0；裁判长确认胜者 |
| 退赛 `RET` | 实际局/比分、退赛方、结束时间 | 保留实际比分，不补未完成局 |
| 取消资格 `DSQ` | 裁判长、依据、作用范围 | 不由脚本自动决定 |
| 终止待裁决 `ABANDONED` | 原因、现场状态、裁决事项 | 不自动让领先方获胜 |
| 轮空 `BYE` | 签位来源 | 推进签位，不计实际比赛或休息负荷 |

特殊结果不是随意录入一组比分。小组参赛单位不能完成全部比赛时，最终排名排除该单位及其全部对阵贡献，但原比赛、比分和审计历史保留；其他参赛者的对应统计也同步排除。

## 迟到与场间休息

默认提前 10 分钟检录。场地、对手、裁判和休息条件就绪后记录有效叫场，5 分钟未到只提醒裁判长，不自动判负。

同一运动员两场实际比赛之间默认至少 60 分钟；30—59 分钟仅裁判长逐次批准后放行，低于 30 分钟仍拒绝。跨所有项目按运动员 ID 计算，双打展开四名成员；WO/BYE 不产生休息起点，RET 按实际结束时间计算。

## 更正与晋级

排名和晋级是比赛结果的派生数据，不是不可追踪的手填终值。上游结果更正时先计算影响；后续比赛未开始且规则允许时事务重算，后续比赛已开始时进入人工处置。详细控制见[换边撤销与更正](换边撤销与更正.md)。

阶段 6 已实现：结果确认与重开在同一事务内推进或撤回胜者/负者签位、撤回受影响的小组名次确认；重开前裁判台与后台都先展示影响预览；后续对阵已开始或已有结果时整条命令拒绝，裁判长只能登记人工处置（维持原结果或线下裁决），系统不自动换人、抹分或覆盖历史。暂停、取消、重赛的系统内执行流程未实现。

管理员补录的「仅结果记录」只保存逐局比分与结局（每局须恰好在结束的那一分停下，WO 不补比分，RET/DSQ 保留实际比分和中断局，终止不产生胜方），不生成回合、发接发或换边过程；须由补录人以外的裁判长复核锁定才计入名次与晋级。

## 当前禁止的假设

- 不假设弃权一律记为固定比分。
- 不假设退赛与取消资格对排名等价。
- 不把项目默认写成学校现行规程；正式赛事必须采纳并冻结。
