# 赛务口径决定（2026-10-27）

> 背景：全赛制并发仿真（M1—M6）留下 SF-01—SF-06 和一批「设计未定义 / 需组织方确认」的口径。

> 本文件是这批口径的唯一记录。依据只引用 BWF 官方文本，逐条写明条款号；BWF 没有规定的，写明是本项目取的做法。

> 与 [分组排名与特殊结果](分组排名与特殊结果.md) 冲突时以本文件为准；**休息间隔仍按用户 2026-09-25 的决定不在系统内检查**。

## 一、排名

| 编号 | 决定 | 依据 |
|---|---|---|
| R-1 个人小组 | 维持现有规则链：胜场 → 两方看直接胜负 → 三方及以上比全组净胜局 → 净胜分，**每一层比完只剩两方时回到直接胜负**，不在缩小子集上重算；仍有三方以上相同则抽签。现有「校园演示排名方案 v1」已是这一顺序，改名并标注依据 | GCR 16.2.1—16.2.4.2 |
| R-2 团体小组 | 改为：对抗胜场 → 两队看相互对抗 → 三队及以上依次比对抗净胜、小场净胜、局净胜、分净胜，**每一层比完剩两队即回到相互对抗**；仍相同抽签。现行实现要全部比完才看相互胜负（M5 R4 S1 TEAM/A 两种口径结果相反），需改 | GCR 16.3.1—16.3.6.2 |
| R-3 小组未完赛 | 一名（对）选手因伤病、取消资格、弃权、退赛等**没有打完本组全部比赛**，其全部小组成绩删除（等同现有「排除」），**自动生效**，不再整组卡住等裁判长手工排除；比赛中途退赛也算没打完 | GCR 16.2.5 |
| R-4 团体未完赛 | 一队没有打完本组全部对抗，其全部成绩删除；单个小场因伤病退赛或认输，**按「认输方不再得分」补完计入**（例如 15:21 时退赛记 15:21、0:21） | GCR 16.3.7、16.3.8 |
| R-5 旧结果 | 已确认的历史名次按确认时保存的方案键复现，新方案只作用于之后的确认 | 本项目做法（与「规则快照链」一致） |

## 二、弃权、退赛、取消资格

| 编号 | 决定 | 依据 |
|---|---|---|
| W-1 未到场 | 叫场后未到，由裁判长判「未到场」，比赛以 WO 判给到场一方 | GCR 13.7 |
| W-2 一项退出 | 选手在一个项目里**退赛或赛前退出**，同一赛事其余项目一并退出（未开始的比赛逐场以 WO 判给对手）；系统列出受影响比赛，裁判长确认后执行 | GCR 13.6.1 |
| W-3 团体内退赛 | 在一场对抗里退赛 / 退出的队员，本场对抗后续小场不再上场且不得替换；之后的对抗可以再上 | GCR 13.6.2、13.6.2.1 |
| W-4 取消资格 | 裁判长取消某人资格 → 该人**所有项目**未开始的比赛以 WO 判给对手，已打完的淘汰赛结果保留，小组成绩按 R-3 删除；双打搭档在其他项目照常；团体赛中被取消资格的队员不得再上任何小场 | ITTO 3.6.2.2；GCR 13.6.3 |
| W-5 跨多场追溯 | 不做「一键取消全部成绩」：BWF 不回溯改写已打完的淘汰赛，W-4 已覆盖需要的范围 | ITTO 3.6.2.2 |
| W-6 团体缺人 | 出场名单允许把某个小场空着，空着的小场按认输处理（0:21、0:21 计入），对抗照常结算；不再因「必须填满全部小场」卡死 | GCR 16.3.8 |
| W-7 团体退赛 | 一队整体退出：其余对抗以 WO 判负，小组成绩按 R-4 删除 | GCR 16.3.7；ITTO 3.8.7 |

## 三、淘汰签位

| 编号 | 决定 | 依据 |
|---|---|---|
| K-1 一方空位 | 淘汰赛一侧因对手弃权、取消资格或小组出线人数不足而为空，**另一侧以 WO 晋级**，不再停在 SCHEDULED | GCR 13.7 的同一处理；BWF 没有「空位」条款，本项目取的做法 |
| K-2 双方都不能比 | 两方都未到或都退出：本场无胜者，**下一轮对手以 WO 晋级**；三四名赛同理 | BWF 未规定，本项目取的做法（与常见赛事软件一致） |
| K-3 不递补 | 不从小组第 3 名或候补名单递补（BWF 的递补只在抽签后、首轮赛程发布前） | GCR 13.1.4 |

## 四、赛程、场地与开赛

| 编号 | 决定 | 依据 |
|---|---|---|
| S-1 延误不算冲突（SF-02） | 一侧已开始或已结束的比赛与另一场的计划时间重叠，记为**延误提示**，不算硬冲突；硬冲突只在两场都未开始时成立 | ITTO 3.5.17：赛程由裁判长批准，出场顺序按「接着打」执行；本项目做法 |
| S-2 发布只校验本次改动（SF-05） | 发布赛程只拦截**本次草稿改动涉及的比赛**上的硬冲突；与本次改动无关的已有冲突列为「待处理」并给出改期入口，不再挡住整个赛事 | 本项目做法 |
| S-3 名单与个人赛程（P-09） | 出场名单提交时，若队员的个人项目比赛与该小场计划时间重叠，**提示但不拒绝**；真正上场时由 S-4 拦截 | ITTO 3.8.5.1（裁判长排出场顺序时尽量不让同一人连打） |
| S-4 选手正在比赛不能开赛（P-08） | 某场的任一选手在另一场比赛进行中（已开始未结束），本场不能开始；裁判工作台提示「XX 正在 X 号场比赛」 | ITTO 3.5.17 的出场安排前提；本项目做法 |
| S-5 转场（P-05） | 裁判长可把**暂停中**的比赛转到另一块空场地，比分、发接发保持不变，从暂停处继续；公开页随即显示新场地；转场写审计 | Laws 16.3.3；GCR 17.1.1 裁判长总负责 |
| S-6 不设「取消比赛」 | 比赛只能以正常完赛、WO、RET、DSQ 结束；没有单独的「取消」状态 | BWF 文件中无「取消」结局 |
| S-7 开错比赛（错场） | 比赛还没打完第一局时，裁判长可以「作废本场计分」，比赛回到未开始，原事件保留在审计里并标记作废；第一局打完后不能作废，只能走更正 | 本项目做法（BWF 无对应条款，错场属记录错误） |

## 五、报名与裁判

| 编号 | 决定 | 依据 |
|---|---|---|
| E-1 同一学号单位不一致 | 一名参赛者在一个赛事里只代表一个单位；不同单位的报名**拒绝**并提示已有单位 | BWF 体系里选手代表一个会员协会；本项目做法 |
| O-1 裁判轮换 | 自动建议改为**负荷均衡优先**：先排执裁场数少的；同一裁判不连续执裁超过 2 场（之后至少空一个场次）；不让裁判执裁本单位选手的比赛（能避开时） | ITTO 3.5.11.3、3.5.11.4、3.5.21（中立） |
| O-2 执裁人登记 | 共用账号模式下，裁判在工作台**取得控制前填写本人姓名**；姓名记在控制会话与审计里，工作台显示当前执裁人（比赛详情与成绩册的展示见实施状态）；换人须重新填写（等同交接） | 用户 2026-10-27 决定 |
