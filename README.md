# 校园羽毛球赛事编排与裁判管理系统 V1.0

> 当前状态：阶段 1 已独立复验通过；S2-008 换边待办语义与 S2-009 特殊结果作废也已于 2026-09-20 通过独立复验。阶段 3 场地图裁判工作台获独立“有条件通过”；UI-01-B 与联合总判原为“不通过”，F-001—F-005 已由 Codex 本地修复、尚待独立复判。正式 BWF 规则采用、真机、真人裁判和生产部署仍未完成。

本项目计划建设一套中文响应式网页应用，让电脑、平板和手机共享同一后端和权威比赛数据，覆盖报名、分组、赛程、主裁判执裁、成绩复核、名次、成绩册和公开查询。

## 本机启动

当前 Mac 已创建未提交的 `.env`、`.env.seed` 以及开发数据库。首次从干净检出启动时，先根据 `.env.example` 配置本机连接和随机密钥，再准备单独的 `.env.seed`。

```bash
pnpm install --frozen-lockfile
pnpm run db:migrate
pnpm run db:seed
pnpm dev
```

浏览器访问 `http://127.0.0.1:3000`。本地示例账号和密码只保存在被 Git 忽略的 `.env.seed`；生产环境若发现示例账号配置会拒绝启动。详细步骤见 [`本地启动与手机访问`](docs/knowledge-base/07-使用部署/本地启动与手机访问.md)。

## V1 范围

- 赛事管理员、组织/编排人员、临场主裁判员、裁判长/授权负责人、只读公众五类角色。
- 男单、女单、男双、女双、混双由后台手工录入或 Excel/CSV 批量导入，保留跨项目人员冲突检查；再完成分组、循环赛/淘汰赛编排、场地与时间安排、裁判指派。
- 可实际执裁的单双打主裁判端，包括抛硬币、逐分记分、发接发分配、左右调整、物理换边、撤销、更正、操作历史和结果确认。
- 成绩复核、名次和晋级、成绩册导出、打印以及隐私受控的公开查询。

暂不开发原生 App、团体赛、支付、短信、直播、AI 视频判分、自动动作识别、多租户平台和离线合并记分。

## 当前已实现边界

- Next.js 中文页面骨架：首页、赛事管理、我的执裁、公开查询、设置和登录。
- PostgreSQL 15 的可追踪迁移；开发库与 `_test` 测试库分离。
- Better Auth 数据库会话和密码哈希；公开注册关闭。
- 服务端检查账号状态、赛事角色和具体裁判指派。
- 单场权威快照和只追加事件；服务端事务执行幂等、预期版本、租约代次、心跳和裁判长接管。
- 传统 21、替代 3×15、单局 21 三个演示配置，以及可序列化、可重放的纯规则引擎。
- 纯引擎已通过统一命令 API 接入 PostgreSQL 和场地图主裁判工作台；界面只投影 `logicalCourts`、`physicalEnds` 和发接发人，不复制计分或换位算法。
- 场地图已覆盖单双打四格站位、拟首发/拟首接选择、双打手动换位、物理换边与本机翻转视角；本机翻转不写入比赛状态。
- `CORRECT_PHYSICAL_ENDS` 使用 `obligationRelationship` 区分“已完成换边”与“仅更正端位、继续保留待办”；撤销/减分先预览，不直接算术减分。
- 所有写入共享单一在途锁；服务器确认前不乐观改分，响应未知时使用原 `commandId` 查询或重试。
- 服务端公开字段白名单、健康检查、中文结构化错误和脱敏日志基础。
- UI-01-B 每日赛程与比赛详情已实现为非生产、显式开关控制的隔离模拟预览；它使用独立虚构 DTO，不读取数据库、认证或裁判 API，也不替换正式 `/public`。

未实现项以 [`需求验收追踪矩阵`](docs/knowledge-base/01-项目规划/需求验收追踪矩阵.md) 为准。

## 质量命令

首次从干净检出运行测试前，复制 `.env.test.example` 为不提交的 `.env.test`，填写本机 `_test` 数据库、至少 32 字符的测试密钥及两个本地模拟身份。`ALLOW_DEMO_ACCOUNTS=true` 只授权测试种子创建身份，不会开放网页公众注册。

```bash
pnpm run lint
pnpm run typecheck
pnpm test
pnpm run test:e2e
pnpm run build
pnpm run test:production-startup-security
```

`pnpm test` 会先验证数据库名以 `_test` 结尾，再迁移并幂等写入测试种子；缺少 `.env.test` 时会明确指向模板。Playwright 浏览器由 `pnpm exec playwright install chromium` 安装，不进入 Git。

联合独立验收已复跑并确认上一轮门禁数字一致；这些数字不等于联合总判通过。F-001—F-005 收口后的最新本地结果为 `pnpm test` 101/101、Playwright 36/36（阶段 1 为 8、阶段 3 为 6、UI-01-B 为 22）、规则/命令 schema/场地投影 64/64、lint/typecheck/build 通过、生产启动安全 4/4、同步脚本 10/10、阶段 3 图片哈希 6/6 和 UI-01 图片哈希 45/45；详情见[测试记录](docs/knowledge-base/05-测试验收/测试记录.md)。所有视口证据仍是 Chromium 模拟，不等同于独立复判、真机、真人裁判或生产部署验收。
